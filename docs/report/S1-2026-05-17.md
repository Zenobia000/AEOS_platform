1. CEO 確認預算（Phase 1 infra 月支出目標 < $150）
2. CTO 開 Hetzner Cloud Account（信用卡 + VAT）
3. 開 1 台 CX22（2 vCPU / 4 GB / 40 GB SSD，€4.5/月）
4. Cloudflare DNS A record 指向 VM
5. 部署 docker-compose for prometheus/grafana/loki（用 grafana/lgtm stack）
6. FastAPI app 加 `prometheus-fastapi-instrumentator`

### #3 HMAC 解鎖（不必等 pilot）

CTO 可立即在 LINE Developers Console 開 sandbox channel（免費）拿 Channel Secret，先寫驗簽 code + 測試。pilot 簽下後再切換到客戶真實 Channel Secret。

### #5 Oncall 解鎖

1. CEO 用 `funngo.ai` 域名開 Slack workspace（Free plan）
2. 建 channels：`#engineering`、`#oncall`、`#alerts`、`#general`
3. CEO 註冊 PagerDuty Free（5 user 內免費）
4. CTO 接 primary oncall schedule + escalation policy

### #6 Pilot 客戶簽約（critical path）

> **每延 1 週簽約 → 整 Phase 1 時間軸右移 1 週**

1. 填 `PILOT-ICP-2026-05.md` §3.1 30 個候選名單

5. 通知 CTO 啟動 S2
