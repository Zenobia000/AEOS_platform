# Validation & Kill — 可證偽實驗與預先承諾

> 一個賭注若沒有能殺死它的條件，它就不是賭注，是信仰。這份把信仰變成可證偽實驗，並**在投入前**承諾殺死條件。

---

## 1. 實驗結構

整個 MVG（[`02-mvg-build-sheet.md`](./02-mvg-build-sheet.md)）是一個實驗，回答 [`00-the-bet.md`](./00-the-bet.md) 的賭注。

```
假設：一坨真實混亂知識，能在數天內變成「人類願意採用的草稿回覆」，
      且治理介入成本低於請真人。
實驗：對 1 個真實 pilot 客戶，跑 Draft Mode ≥ 2 週，量「草稿採用率」。
讀數：採用率 = (approve + edit-and-send) / 全部草稿
      其中 approve（原樣送出）才是「真正好用」的強訊號。
```

## 2. 證明 / 殺死的數字（按子賭注）

| 子賭注 | 量尺 | 證明（continue） | 殺死（stop / pivot） |
|---|---|---|---|
| **B1** 知識可用 | 測試集 50 題 pass rate（`eval.py`） | ≥ 70% W1、≥ 80% pilot 末 | 調 3 輪仍 < 50% |
| **B1** 真實採用 | LINE 草稿**原樣 approve 率** | ≥ 50%（且總採用 ≥ 70%） | 總採用率 < 40% |
| **B2** 治理划算 | expert 每則花的秒數 × 量 | 比真人寫一則省 ≥ 50% 時間 | reject 率 > 30%（人在救火不是審核） |
| **B3** 零件可換 | pilot 末跑：記憶匯出→注入、LINE↔Web 換身體 | 各成功跑通 1 次 | 非生死；做不到 → 降 Phase 2 |
| **B4** 單位經濟 | 該租戶月 LLM 成本 vs 月費 | 毛利 ≥ 50%（LLM 上限 $300/月內） | 毛利長期為負且無轉正路徑 |
| **市場** | 8 週內簽到願給真知識+真對話的 pilot | ≥ 1 家（目標 3–5） | 8 週 0 家 → wedge 選錯 |

> **唯一北極星數字**：**草稿原樣 approve 率**。盯一個數字，不被六個數字分心。

## 3. 時間軸與閘門

```
W0     簽 pilot + 簽 DPA（市場賭注第一關，最早驗）
W1     eval.py 對測試集打 B1（最致命，最早驗，不用等 LINE）
       └─ pass rate < 50% 且補救無效 → 立即停，別繼續寫 LINE 串接
W2–W3  全鏈路跑通 + 真實知識上線 Draft Mode
W4–W6  連續量採用率（≥ 2 週穩定讀數）
W6     ▶ Go/Kill 決策點（見 §4）
W7+    只有 Go 才繼續：談自動發 canary、第 2 個租戶、加回延後清單
```

**硬閘門**：W1 的 B1 測試集若崩，**不准進 W2**。先救知識品質或承認賭注錯，不准用「先把 LINE 串完再說」逃避。

## 4. 預先承諾（Pre-mortem，現在簽，W6 不准賴）

W6 決策點，任一為真 → **Kill 或 Pivot，不准「再寫一版文件 / 再補一輪願景」**：

```
KILL：
  × 草稿總採用率 < 40%（B1 死：核心轉換不成立）
  × expert reject 率 > 30%（B2 死：治理在救火）
  × 單租戶毛利長期為負且無轉正路徑（B4 死：不是生意）
  × 8 週簽不到任何願配合的 pilot（市場死：不痛 / wedge 錯）
PIVOT（不殺賭注但要改）：
  ⚠ 採用率 40–50%：限再調 2 輪，調不上去轉 KILL
  ⚠ B3 零件互換做不到：降 Phase 2，不影響 W6 Go 決策
```

**Go 訊號（全部成立才放大）**：草稿原樣 approve ≥ 50% 且總採用 ≥ 70%；expert 每則省時 ≥ 50%；毛利 ≥ 50%；≥ 1 家 pilot 真實跑通 2 週。

> 簽名欄（CEO 投入前填）：本人承諾上述 KILL 訊號任一觸發即停手，不以追加文件 / 願景 / 功能規避。
