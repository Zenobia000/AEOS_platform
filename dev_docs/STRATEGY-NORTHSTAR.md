## 1. Mission

> 把「製造一位能上班的 AI 員工」從數月的人工工程，變成**數天、近乎零邊際成本的工廠量產**——並讓這條產線越用越快、越用越便宜。

---

## 2. Strategy

我們的產品不是 AI 員工，是**量產 AI 員工的工廠**（the machine that builds the machine）。

第一性原理：一位 AI 員工 = 記憶 + 身體 + 技能，三者皆可數位複製，理論邊際複製成本趨近於零。今天「製造」一位可上線員工的成本之所以高，浪費全在**人工**（陪訓、標註、審核、逐案調 prompt）。因此價值與護城河不在員工本身，而在那條能把混亂知識可靠量產成合格員工的產線。

我們的打法：**切口窄、架構寬**。對外從 AI 藍領（客服一線）這個大廠盲區切入；對內自第一天起就是「記憶/身體/技能可抽換、可治理、可監控」的工廠架構。把製造邊際成本壓向零，再用自我強化飛輪把領先複利化。

---

## 3. The Bets

我們押四個賭注。每個賭注標明**為何敢賭**與**賭錯的訊號（kill signal）**。

### Bet 1 — 工廠即產品

**賭**：當複製一位 AI 員工趨近零成本，價值會從「員工」遷移到「產線」。護城河在量產與治理能力，不在單一 agent 多強。

**為何敢賭**：模型會商品化（紅杉預言 LLM wrapper 無護城河）；能持續沉澱的是 Skill/Knowledge/Evaluation/治理體系。

**Kill signal**：若客戶願付的價值集中在「單一超強 agent」而非「可治理可量產的產線」，則命題錯，需重估。

### Bet 2 — 三種可抽換零件

**賭**：把記憶、身體（runtime/harness）、技能做成**獨立可抽換、可版控、可移植**的標準件，是量產與生態的總開關。記憶可匯出注入、身體可換通道、角色可重扮。

**為何敢賭**：標準化零件是製造業真正的發明（福特）。模組化 → 垂直整合 + 零件市場 + 跨腦身互換全部解鎖。

**Kill signal**：若記憶移植/身體換裝在合規（tenant 隔離、PII）約束下無法可靠運作，模組化紅利落空，退回「整體重訓」模式。

### Bet 3 — 自我強化飛輪

**賭**：上線員工的遙測回流，會讓工廠量產的員工越來越強、越來越便宜（Tesla 車隊 → FSD 同構）。這是最深的護城河。

**為何敢賭**：資料飛輪是 AI 時代三類新護城河之一；AEOS 的旁路閉環（遙測→Compiler→再訓練）已具雛形。

**Kill signal**：若飛輪一輪都跑不通（遙測無法有效轉成製造成本下降或品質提升），則「越用越強」不成立。

### Bet 4 — AI 藍領 Wedge

**賭**：可長期守住的市場是**前線/藍領**（客服、維修、零售、物流現場），不是白領 Copilot。大廠毛利低、不性感、不會進。

**為何敢賭**：全球 30 億藍領工作者；缺工、高流動、訓練成本高、24/7 需求；大廠 Workspace/Office/CRM 全服務白領，藍領無原生方案。

**Kill signal**：若大廠針對藍領現場推出原生方案，或藍領客戶採購邏輯無法支撐單位經濟，需重設 wedge。

## 4. OKRs (18 個月)

### Objective O1 — 證明第一條產線細胞可運轉 (0–6 月，MVG)

> Minimum Viable Grand-design：用最聚焦範圍驗證整個工廠命題（Tesla Roadster 之於電動車）。

| Key Result | 目標 |
|---|---|
| **KR1.1** 製造週期（混亂知識 → 出廠驗收） | ≤ 7 天（對比真人 3 個月） |
| **KR1.2** 製造過程人類介入 | ≤ 1 次（僅 G5 專家簽核） |
| **KR1.3** 記憶模組匯出 → 注入新胚胎成功率 | 100% |
| **KR1.4** 同腦雙通道（LINE + Web）行為一致性 | 通過驗收 |
| **KR1.5** 飛輪閉環（遙測→漂移→召回→再訓練上線） | 跑通 ≥ 1 輪 |

### Objective O2 — 證明可量產且能自我強化 (6–18 月)

| Key Result | 目標 |
|---|---|
| **KR2.1** 七閘門自動通過率（人類只簽 G5） | ≥ 95% |
| **KR2.2** 單一租戶量產職位類別數 | ≥ 3 |
| **KR2.3** 季度 FCR 提升（飛輪兌現） | ≥ X%（baseline 後設定） |
| **KR2.4** 每位出廠員工製造邊際成本下降 | ≥ Y%（baseline 後設定） |
| **KR2.5** 互換矩陣（換記憶/換身體/換技能）三格 | 全數生產驗證通過 |

> X/Y 待 pilot baseline 量測後填入；硬填為假數字。

## 5. What We're NOT Doing (Non-goals)

明確不做，與賭注同等重要：

- **不進 white-collar Copilot 戰場** — Google / Microsoft / Salesforce 主場，進去送死。
- **不賣裸 Agent + RAG + Workflow Designer** — 會被 AI 動態生成取代；賣的永遠是治理過、可監控可召回的零件與產線。
- **不做跨 tenant 記憶移植** — 合規鐵律（RLS / PII 隔離），任何互換協議都在隔離邊界內運作。
- **不在流程刪對前自動化** — Elon 五步法第 5 步神聖：先質疑→刪除→簡化，最後才自動化，否則只是用機器人放大愚蠢流程。
- **MVG 階段不做**：L4 營運記憶、跨企業勞動網、第三方零件市場、訓練室全自動自我博弈、多租戶量產。
- **不綁單一 LLM 供應商** — 模型外包但抽象化（多模型層）。

## 6. Metrics That Matter

**North-Star Metric（唯一最重要）**：

> **白癡指數** = 製造一位通過驗收 AI 員工的實際成本 ÷ 理論下限（儲存 + 一次驗收算力）。
> 目標：18 個月內壓低**一個數量級**。

**支撐指標**：製造週期、人工介入點數、$ / 出廠員工、飛輪閉環輪次、FCR 趨勢、漂移→召回時效。

**護欄指標（不可破，否則一切無效）**：跨 tenant 違規 = 0、PII 洩漏 = 0、SOP 遵守率 ≥ 99%、高風險回答攔截率 ≥ 99.9%。

## 7. Operating Cadence

| 節奏 | 內容 | 對映 |
|---|---|---|
| **每週** | 產線 cycle-time + 閘門自動通過率 review | KR1.1 / KR2.1 |
| **每月** | OKR check-in + 飛輪輪次 + 白癡指數追蹤 | §4 / §6 |
| **每季** | **Bet 重估**：逐一檢視 §3 四個 kill signal；OKR 重設 | §3 / §4 |
| **每個 Freeze Gate** | multi-role critique（PM/SA/Arch/SD/QA/SRE…）後簽核 | devteam Lane A/B |

> 季度 Bet 重估是這份策略的活門：任一 kill signal 觸發，該賭注與相依 OKR 立即進入重估，而非默默推進。
