🟢1. 對話鏈路 LINE → AI → user

📨 LINE Channel Gateway (MC-011)
  • Webhook HMAC-SHA256 驗簽 + ≤1s ACK
  • Event dedup webhook_event composite PK
  • LINE userId pseudonymize SHA256+salt
  • Push API outbound 4xx fail / 429+5xx retry / max → DLQ
🗣 Conversation 引擎 (MC-010)
  • 6 態狀態機 open / active / waiting_human / resolved / closed / archived
  • Monthly partition message 表 PARTITION BY range(created_at)
  • 30min idle timeout → closed worker cron
  • handoff（policy_deny / user_request）
🤖 AI Runtime (MC-009)
  • EmployeeRuntime 借鑑 nanobot agent loop
  • AnthropicClient Sonnet 4.6 / Haiku 4.5 可切
  • Frozen snapshot per turn
  • 3 Governance Hooks Audit / Policy / Quota
🔧 Tool 系統 (MC-006)
  • ToolExecutor + InternalToolRegistry
  • builtin: search_knowledge pgvector cosine RAG top-K
  • builtin: request_human_handoff
  • tool_invocations JSONB 寫入 message（含 kc_refs）
⚙️ Worker polling (4 cycles)
  • IdlePoll 30min sleep close
  • DraftPoll user 最後一則 → LLM
  • OutboundPoll pending → LINE Push
  • TestRunPoll pending test_run → TestSetRunner
  • SELECT FOR UPDATE SKIP LOCKED 並發安全
✉️ Draft Mode (PRD §5.4)

  • 所有動作進 audit_log（trace expert.draft_*）

🟠4. TestSet + Skill Quality AC-001 pass rate

🗂 Schema (3 表)
  • test_case: name / user_input / expected_outcome / expected_keywords
  • test_run: skill_slug + skill_version snapshot + pass_rate float
  • test_run_case: composite PK + status 5 態 + judge_score + judge_reason
  • 全 RLS tenant_id 隔離
🤖 Judge Strategy (Protocol)
  • KeywordJudge Phase 1 簡單版 regex 白名單
  • LLMJudge S5 升級 Haiku 4.5 語意比對
  • LLMJudge 自帶 keyword fallback（LLM 失敗不炸 test）
  • 容錯 JSON parser（抓 {} 區段，markdown wrapper OK）
⚙️ TestSetRunner
  • 每 case 走 LLMClient one-shot（不污染 conversation）
  • judge 注入：跑 N 個 case → status='completed' + pass_rate
  • 失敗 case 標 'error'；audit test_run.completed
  • worker TestRunPoll cycle 自動撿 pending run
🌐 REST API (6 endpoint)
  • GET /cases / POST /cases / POST /cases/{id}/disable
  • POST /runs / GET /runs/{id} / GET /runs/{id}/cases
  • 受 auth dependency 保護
  • 422 / 409 對映完整

🔐5. 治理 + 安全 S5 Pilot hard gates

🔑 Auth + Sessions
  • expert_account: bcrypt + role (expert/admin)
  • expert_session: bearer token + 30d expiry
  • AEOS_AUTH_REQUIRED env gate
  • 防 user enumeration（unknown/wrong/disabled 都回 same msg）
  • disable 同步 revoke all sessions
🛑 Kill Switch (UF-004)
  • tenant_setting.ai_enabled boolean
  • 二次確認（confirm_tenant_id 比對）
  • DraftProcessor 每 turn 查 DB <1ms
  • Disabled → 跳 LLM + 建 handoff + audit
  • Slack P0 通知（best-effort）
🎚 Canary Routing
  • per-tenant 0-100% 漸進放鬆
  • 確定性 bucket: SHA256(conv.uuid)[:4] mod 100
  • 同 conversation 永遠同 bucket（UX 一致）
  • admin API + audit canary.percent_changed
🛡 PII Masking (SEC §6.1 #11)
  • email / 手機 / 市話 / 身分證 / 信用卡 / 銀行
  • 信用卡 Luhn checksum 過濾 false positive
  • raw PII 永遠不進 DB / log
  • audit pii.redacted_in_ingress + Prometheus counter
📋 Audit Log (append-only)
  • trigger 阻擋 UPDATE / DELETE（PG insufficient_privilege）
  • JSONB payload + 跨 tenant 索引
  • resource_type + resource_id 串接 conversation / outbound / KC
  • 14+ event types（draft.* / kc.* / kill_switch.* / canary.* 等）
⚡ 3 Governance Hooks
  • AuditHook: LLM/tool call 前後 audit
  • PolicyHook: tool allow/deny + DB rule
  • QuotaHook: token / cost 預算追蹤
  • engineering-charter §1 三大支柱落地
